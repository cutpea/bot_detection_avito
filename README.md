# bot_detection_avito

  Решение задачи детекция ботов -  по событиям внутри суточного окна построить модель, которая присваивает каждой cookie_id оценку от 0 до 1: чем выше значение, тем вероятнее принадлежность к положительному классу.

Краткий подход к решению задачи:
- осмотреть датасет, выявить пропуски, дубликаты
- создать временные окна cookie
- построить признаки
- подобрать параметры для lightgbm
- сделать валидацию по времени
- сделать walk-forward по всем окнам, чтобы получить n_rounds_final
- применить бэггинг по 5 сидам на полном трейне
- провести честную проверку без утечек

Решение представлено на Python 3.12.14. Файл requirements.txt содержит версии библиотек, которые использовались в проекте. Само решение представлено в файле bot detection.ipynb, результаты в файле submission.csv. В папке data лежат train и test, файл events.csv.gz не загружается, так как слишком большой. metric.py используется для оценки модели
